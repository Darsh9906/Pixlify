A modern photo gallery web application built with HTML, CSS, and JavaScript using the Unsplash API.

🚀 Features
Search images by keyword
Category filters (Nature, Cars, Travel)
Load More functionality
Responsive masonry image layout
Error handling for API requests
Loading states
Dark modern UI
Keyboard support (Enter key search)

🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Unsplash API
Lucide Icons
GSAP

Generate an Access Key.
